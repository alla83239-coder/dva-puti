# ДВА ПУТИ · Алла × Александра

Самостоятельный статический сайт-предпросмотр. Название «Два пути» и визуальная концепция предварительные — их можно изменить после согласования.

## Структура
- `index.html` — главная страница
- `alexandra.html` — «Темнолесье»: Таро, ритуальные работы и программные свечи
- `alla.html` — авторские направления Аллы
- `booking.html` — форма подготовки текста обращения
- `styles.css`, `app.js` — оформление и интерактивность
- `assets/` — декоративные SVG

## Публикация на GitHub Pages
1. Создать отдельный публичный GitHub-репозиторий, например `dva-puti`.
2. Загрузить в корень репозитория все файлы и папку `assets`.
3. Открыть **Settings → Pages**.
4. В разделе Build and deployment выбрать **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем сохранить.
5. После публикации сайт будет доступен по адресу `https://<username>.github.io/dva-puti/`.

## Важно о текущем прототипе
- Форма на `booking.html` формирует текст обращения и позволяет его скопировать. Она не отправляет заявки автоматически и не сохраняет персональные данные.
- Контакты: Александра — `@witchwood`, Алла — сообщество VK `https://vk.ru/soulmatetarot`.
- Стоимость матричных и других авторских разборов Аллы не зафиксирована на сайте: она указана как уточняемая.
- Цены Александры по Таро, ритуалам и свечам перенесены из предоставленного PDF-прайса. Условия скидки также перенесены.
- Перед публикацией нужно подтвердить контактные ссылки, дополнительные авторские форматы Александры и актуальность стоимости.
- Сайт не заявляет, что эзотерические практики гарантируют отношения, доход, здоровье или иной конкретный результат.
