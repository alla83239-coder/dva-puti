# ДВА ПУТИ · Алла × Александра

Самостоятельный статический сайт. Рабочее название и визуальную концепцию можно изменить после согласования.

## Структура
- `index.html` — главная страница
- `alexandra.html` — «Темнолесье»: Таро, ритуальные работы и программные свечи
- `alla.html` — авторские направления Аллы
- `booking.html` — форма подготовки текста обращения
- `styles.css`, `app.js` — общий стиль и интерактивность

## GitHub Pages
Открой **Settings → Pages**. В Build and deployment выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажми Save.

После публикации сайт будет доступен по адресу:
`https://alla83239-coder.github.io/dva-puti/`
