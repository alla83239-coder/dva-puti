# Темнолесье · Александра

Адаптивный статический сайт авторского пространства Александры.

## Страницы
- `index.html` — главная страница Темнолесья
- `alexandra.html` — полный каталог: Таро, авторские триплеты, диагностика отношений, ритуальные работы и программные свечи
- `about.html` — страница Александры
- `booking.html` — трёхшаговая заявка: услуга, дата/время, контакты
- `account.html` — локальная регистрация, вход и история заявок

## Дизайн и изображения
- Montserrat, изумрудно-золотая палитра, градиенты и объёмные кнопки.
- Портрет Александры: `assets/alexandra-photo.webp` — оптимизированная версия исходной фотографии.
- Фотографии леса, карт и свечи загружаются с Unsplash. Источники/авторы указаны внизу главной страницы.
- SVG-иконки: `assets/icons.svg`.

## Публикация
GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**.

Адрес: https://alla83239-coder.github.io/dva-puti/

## Заявки: текущий режим
- Заявки и демонстрационные профили сохраняются в `localStorage` этого браузера.
- В профиле хранится PBKDF2-хеш пароля, а не исходный пароль.
- История доступна в том же браузере и на том же устройстве.
- Автоматической отправки заявки Александре, общей базы и Telegram-уведомлений пока нет. Для этого понадобится серверная часть.
- Выбранные дата и время — пожелание клиента, а не подтверждённый свободный слот.
