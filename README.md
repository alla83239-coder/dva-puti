# ДВА ПУТИ · Алла × Александра

Адаптивный статический сайт двух авторских направлений.

## Страницы
- `index.html` — общая главная
- `alexandra.html` — «Темнолесье»: Таро, ритуальные работы, программные свечи
- `alla.html` — авторские разборы Аллы
- `joint.html` — совместные психологические сказки, расклады на Таро и Оракулах
- `booking.html` — трёхшаговая заявка: услуга, дата/время, контакты
- `account.html` — локальная регистрация, вход и история заявок
- `services.js` — каталог услуг и информация для формы
- `styles.css`, `app.js` — дизайн, адаптация, меню, переходы и логика форм
- `assets/` — портреты авторов, SVG-фоны и золотые SVG-иконки

## Публикация
GitHub Pages настраивается через **Settings → Pages → Deploy from a branch → main → / (root)**.

Адрес: https://alla83239-coder.github.io/dva-puti/

## Текущий режим заявок
- Заявки и демонстрационные профили сохраняются в `localStorage` этого браузера.
- В пароле сохраняется PBKDF2-хеш, а не исходный пароль.
- История доступна из личного кабинета в том же браузере и на том же устройстве.
- Автоматической отправки заявок авторам, общей базы и Telegram-уведомлений пока нет. Для этого понадобится серверная интеграция.
- Дата и время, выбранные в форме, являются пожеланием клиента, а не подтверждённым свободным слотом.
